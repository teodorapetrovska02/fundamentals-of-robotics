# Robotics 1 — Exam Preparation Exercises

Solved exercises prepared for the **Robotics 1 (3ФЕИТ01Л018)** course at the Faculty of Electrical Engineering and Information Technologies (FEEIT), Ss. Cyril and Methodius University in Skopje.

The repository contains exercises covering different topics from the course, implemented and explored using Python, SymPy, Plotly, and Jupyter notebooks.

## Topics

* Robot kinematics
* Differential kinematics and Jacobians
* Robot dynamics
* Trajectory generation
* Robot visualization
* Denavit–Hartenberg transformations

### `script.py`

Contains the supporting functions and `SerialLinkRobot` class used for symbolic calculations, robot modeling, visualization, and interaction throughout the exercises.

### Notebooks

The `notebooks/` directory contains solved exercises organized by topic.

## Technologies

* SymPy
* NumPy
* Plotly
* ipywidgets
* Jupyter Notebook
